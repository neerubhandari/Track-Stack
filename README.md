# Track Stack

## Description

Track Stack is a collaborative project management tool that helps teams to organize, track, and manage their projects and tasks. It provides an intuitive interface to create workspaces, invite members, and structure projects and tasks efficiently. Members within a workspace can collaborate, manage project timelines, and stay on top of tasks in real-time.

## Features

- **Create Workspace**: Users can create workspaces where teams can collaborate.
- **Invite Members**: Workspace owners or admins can invite members to join and contribute to the workspace.
- **Project Management**: Users can create and manage projects inside each workspace.
- **Task Management**: Tasks can be created inside projects, and progress can be tracked.

## Tech Stack

- **Frontend**: Next.js
- **Backend**: Appwrite, Hono (for API services)
- **Authentication**: Appwrite Authentication (JWT)
- **Database**: Appwrite Database
- **Styling**: Tailwind CSS
